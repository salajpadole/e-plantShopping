# Paradise Nursery

## Overview
Paradise Nursery is an online plant shopping application built with React and Redux Toolkit. It allows users to browse plants, explore categories, add products to a shopping cart, manage quantities, and calculate the total purchase amount.

## Features
- Welcome landing page.
- Plant catalogue organized into five categories.
- Plant cards with images, descriptions, and prices.
- Add-to-cart functionality.
- Shopping cart quantity management.
- Increase and decrease item quantities.
- Remove products from the cart.
- Automatic subtotal and total calculation.
- Cart quantity indicator.
- Continue Shopping navigation.
- Checkout placeholder.

## Plant Categories
1. Air Purifying Plants
2. Aromatic Fragrant Plants
3. Insect Repellent Plants
4. Medicinal Plants
5. Low Maintenance Plants

## Installation

1. Clone the repository:
   `git clone https://github.com/salajpadole/e-plantShopping.git`

2. Enter the project directory:
   `cd e-plantShopping`

3. Install dependencies:
   `npm install`

4. Start the development server:
   `npm run dev`

5. Create a production build:
   `npm run build`

## State Management
Redux Toolkit manages the shopping cart state through three reducers:

- `addItem`: Adds a product or increases its quantity.
- `removeItem`: Removes a product.
- `updateQuantity`: Updates the quantity of a product.
